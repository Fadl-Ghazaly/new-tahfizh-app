# Tahfizh-App

Tahfizh management system for Pesantren Darul Ilmi.

## Purpose

Tahfizh-App manages:

- Student data
- Teacher data
- Halaqah
- Sabaq
- Sabqi
- Manzil
- Attendance
- Fluency
- Memorization progress
- Monthly reports
- Rankings
- Dashboard analytics
- School settings

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage
- Recharts
- React Hook Form
- Zod
